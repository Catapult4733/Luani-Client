# 0.4.0-offline.2 — HUD startup parse-error hotfix

Runtime-untested preview; desktop verification remains required.

## Fixed in source

- Rename the HUD button's custom String field from `shortcut` to `shortcut_hint`.
  `Button` inherits a native `BaseButton.shortcut` property of type `Shortcut`;
  redeclaring it prevented the UI scripts from compiling on the owner's desktop.
- Update both tooltip rendering and the HUD factory to use the renamed field.
  The built-in native shortcut resource remains available and unchanged.
- No gameplay, driver, installer, account or backend changes.

## Regression coverage and limits

- A source-only Python regression rejects custom button fields that redeclare
  native BaseButton properties. It failed on the reported field before the fix.
- Added a desktop-only Godot contract preloading the HUD/world dependency chain,
  checking tooltip text and the independent native Shortcut resource.
- Hermes did not execute Godot, the game, headless tests or the installer.
  Source parsing, package contents and download checksums do not prove runtime
  correctness. Gemini/the owner must verify a clean launch of this version.

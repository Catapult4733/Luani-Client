# Luani 0.3.0-offline.3 — compact fixed-size UI

- Small 36×32 toolbar buttons with new original 20px menu/chat/list line icons. The owner's earlier circular icons are no longer displayed.
- Removed the Luani/offline-baseplate/camera badge and bottom control strip.
- Disabled automatic canvas stretching. Window resize repositions centered/right-anchored panels without scaling their dimensions or fonts.
- Compact fixed-size neutral dark menu: Players/Settings tabs, underline selection, and a persistent Leave / Respawn / blue Resume bottom row. No decorative heading/slogan/version footer.
- Compact top-right leaderboard with player count and actual local name. Smaller chat and avatar viewer. Existing first-person camera and gameplay code unchanged.

Reference screenshots guided layout only; no Roblox logos, proprietary icons or cropped artwork are included. No unsupported online settings, fake players or simulated social success were added.

**Runtime untested by Hermes**, respecting the standing no-game-execution instruction. Gemini should run the attached compact-layout/fixed-size and gameplay regression checklist on the development computer.

Quit the client, run the usual install/update command without sudo, then reopen Luani Client:

```bash
curl -fsSL https://new.luani.fyi/client/install.sh | bash
```

Linux x86_64 and ARM64; previous releases and local preferences retained. Installation never launches the game automatically.

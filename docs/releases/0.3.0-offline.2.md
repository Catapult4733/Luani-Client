# Luani 0.3.0-offline.2 — camera and HUD update

- Expanded look range to almost straight up/down, retaining a small anti-flip guard. Horizontal rotation remains unrestricted.
- Full inward zoom enters first person at eye height, hides the local body/name tag, captures the mouse and adds a centered reticle. Scrolling out restores orbit mode. First-person capture is independent of the shift-lock setting; menu/chat/focus transitions release capture while interacting.
- Added the owner's unchanged menu/galaxy, chat and leaderboard SVGs, decoded directly at runtime without an editor import cache.
- Refreshed the HUD with circular icon buttons and open/hover outlines, a centered camera-mode badge, compact controls strip, translucent bordered panels, clearer settings sections, styled tabs and always-visible Resume/Respawn/Leave actions.

The preceding preview was reported working by the owner. **This update is runtime untested by Hermes**, respecting the no-game-execution instruction. Static source grammar/API checks and distribution integrity checks do not establish gameplay correctness. Gemini should follow the attached `GEMINI_OFFLINE_HANDOFF.md` on the development computer.

Linux x86_64 and ARM64. Update/install as a normal desktop user (without sudo):

```bash
curl -fsSL https://new.luani.fyi/client/install.sh | bash
```

Quit the old client before updating, then launch Luani Client again. Preferences and previous releases are retained; installation never auto-launches the game. Chat remains offline/local-only, and no multiplayer, login or Studio is introduced.

#0.4.0-offline.1 — Figma UI and collectable tools

**Runtime untested preview.** Per the owner, Hermes did not execute Godot, the game/editor/headless mode, exporter, engine version probe or installer. Gemini performs actual desktop verification. Completed checks are source grammar, resource/assets, secret/network scan and release/public-byte integrity only.

## UI
- Implements the owner's Figma Settings/Players overlays, local chat, roster, live avatar stage and custom Leave/Respawn confirmations in native Godot controls.
- Exact Figma-exported orbital/chat/player-podium SVGs, local Nunito Sans, charcoal/lavender tokens and36×32 non-scaling HUD controls with20px glyphs and6px gaps.
- Implements hover/pressed/open/focus states, real callbacks and matched tooltips. No top branding badge or old bottom help strip.

## Inventory and interaction
-18 session-only slots, contextual nine-slot hotbar, I/backpack,1–9 equip/put-away, E explicit pickup and Q drop.
-Eighteen finite, scattered original sword/lantern/spring-coil pickups, including near-spawn examples. Three-hit wooden practice targets reset after five seconds.
-Swords animate in first/third person and hit nearby facing/visible targets; lanterns switch actual light/glow; equipped coils raise jump impulse and restore it on unequip/drop.
-Input is gated for UI/text/focus; pickups cannot be claimed twice and capacity failure does not consume world objects. Inventory persists through character respawn, not application restart.

Install/update as normal user, without sudo:

```bash
curl -fsSL https://new.luani.fyi/client/install.sh | bash
```
